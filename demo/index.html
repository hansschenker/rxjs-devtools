rxjs-devtools

Open the Redux DevTools browser extension and pick an instance from its dropdown: Counter, Ticker and Search. Jump, skip, commit and rollback from there and watch the page follow.

No extension installed? Everything below still works, the page just has nothing to talk to. Install it from the Chrome Web Store or Firefox Add-ons ("Redux DevTools").

instrument(reducer, initialState) — Counter

0

Dispatched actions: 0. Try skipping an action in the extension's Inspector and the count recomputes.

instrumentScan(accumulator, seed) — Ticker

–

A plain interval(1000) piped through instrumentScan((ticks) => ticks + 1, 0). Each tick is a next action; use the slider in the extension to travel.
